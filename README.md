# Java Learning Path

Este repositório reúne meus **estudos e práticas na linguagem Java**, abrangendo desde os **fundamentos da programação orientada a objetos** até **Orientação a objetos e tramento de exceções**.

O objetivo é consolidar conceitos essenciais da linguagem Java e desenvolver uma base sólida para aplicações acadêmicas e profissionais.

---

## 📚 Conteúdos Abordados

### 🔹 Fundamentos da Linguagem
- Sintaxe básica  
- Tipos primitivos e variáveis  
- Estruturas condicionais  
- Estruturas de repetição  
- Métodos e escopo  
- Entrada e saída de dados  

### 🔹 Programação Orientada a Objetos (POO)
- Classes e objetos  
- Encapsulamento  
- Herança  
- Polimorfismo  
- Abstração  
- Interfaces  

### 🔹 Tópicos Complementares
- Tratamento de exceções  
- Generics  
- Manipulação de arquivos  
- Introdução à programação gráfica (Swing/JavaFX)  
- Noções de concorrência (threads)
