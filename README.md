# Java Learning Path

Este repositório reúne meus **estudos e práticas na linguagem Java**, abrangendo desde os fundamentos da programação até conceitos de orientação a objetos, tratamento de exceções e recursos intermediários da linguagem.

O objetivo é consolidar conceitos essenciais de Java, desenvolver o raciocínio lógico e construir uma base sólida para o desenvolvimento de aplicações acadêmicas e profissionais.

---

## 📚 Conteúdos Abordados

### 🔹 Fundamentos da Linguagem

- Sintaxe básica
- Tipos primitivos e variáveis
- Operadores aritméticos, relacionais e lógicos
- Conversão de tipos
- Estruturas condicionais
- Estruturas de repetição
- Métodos e escopo de variáveis
- Entrada e saída de dados
- Arrays e matrizes
- Manipulação de strings

### 🔹 Programação Orientada a Objetos (POO)

- Classes e objetos
- Atributos e métodos
- Construtores
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Interfaces
- Classes abstratas
- Modificadores de acesso
- Sobrecarga e sobrescrita de métodos
- Relacionamentos entre objetos
- Composição e agregação

### 🔹 Estruturas de Dados e Collections

- Listas (`List`)
- Conjuntos (`Set`)
- Mapas (`Map`)
- Filas e pilhas
- ArrayList e LinkedList
- HashSet e HashMap
- Iteradores
- Ordenação e comparação de objetos
- Generics
- Expressões lambda
- Stream API

### 🔹 Tratamento de Exceções

- Conceitos de exceções
- Blocos `try`, `catch` e `finally`
- Exceções verificadas (*Checked Exceptions*)
- Exceções não verificadas (*Unchecked Exceptions*)
- Lançamento de exceções com `throw`
- Declaração de exceções com `throws`
- Criação de exceções personalizadas
- Tratamento e propagação de erros

### 🔹 Tópicos Complementares

- Manipulação de arquivos
- Leitura e escrita de dados
- Classes utilitárias da biblioteca padrão
- Datas e horários com a API `java.time`
- Enumerações (`enum`)
- Classes e métodos genéricos
- Noções de concorrência e programação com threads
- Gerenciamento de memória e conceitos de Garbage Collection
- Organização de pacotes e modularização

### 🔹 Boas Práticas de Programação

- Convenções de nomenclatura Java
- Organização e legibilidade do código
- Separação de responsabilidades
- Modularização de classes
- Reutilização de código
- Princípios básicos de código limpo
- Introdução aos princípios SOLID
- Documentação de classes e métodos com Javadoc

### 🔹 Ferramentas e Ambiente de Desenvolvimento

- Java Development Kit (JDK)
- Java Virtual Machine (JVM)
- Compilação e execução de programas Java
- Gerenciamento de dependências
- Maven
- Depuração de código
- Controle de versão com Git
- Hospedagem de projetos com GitHub

## 🎯 Objetivos do Repositório

- Consolidar os fundamentos da linguagem Java
- Aplicar conceitos de programação orientada a objetos
- Desenvolver a capacidade de resolver problemas utilizando algoritmos
- Compreender estruturas de dados e coleções da linguagem
- Aprender a tratar exceções e desenvolver código mais robusto
- Praticar a organização, modularização e reutilização de código
- Construir uma base para estudos futuros em desenvolvimento Back-End
- Registrar a evolução do aprendizado por meio de exercícios e projetos práticos

## 🚀 Tecnologias e Ferramentas Utilizadas

- Java
- JDK
- JVM
- Maven
